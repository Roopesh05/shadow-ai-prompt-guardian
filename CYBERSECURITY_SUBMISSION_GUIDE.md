#### Abstract:
```text
The unauthorized use of public generative-AI interfaces by employees—commonly termed “Shadow AI”—is creating a rapidly escalating and often irreversible data-leakage risk, since sensitive information pasted into such tools cannot be retrieved once submitted. Existing enterprise safeguards operate primarily at the network or domain level, relying on blocklists or discovery platforms that expose breaches only after the fact; because these approaches monitor destinations rather than content, they fail to identify unlisted or newly launched AI tools in real time. To address this gap, we present the Shadow AI Prompt Guardian, a Manifest V3 Chrome extension that intercepts and analyzes prompt content locally, across multiple AI platforms, prior to submission. The detection engine combines regex-based pattern matching, Shannon entropy analysis, and context-aware scoring to identify API keys, passwords, personally identifiable information (PII), and other confidential data. A central design requirement is fully client-side operation, with no network calls, telemetry, or raw-data storage. Evaluated on a 140-prompt categorized dataset spanning five content categories, the system achieved perfect detection performance, with 1.00 accuracy, precision, recall, and F1 score across all categories. A supplementary large-scale stress test using 1,000 combinatorially generated credential-disclosure prompts achieved 95.4% accuracy, surfacing two reproducible failure mechanisms tied to label-style secret phrasing and context-aware score suppression. These results indicate that the proposed approach offers a lightweight, easily deployable, and privacy-preserving alternative to conventional enterprise data-loss-prevention (DLP) browser tools, while the stress test demonstrates the value of adversarial, at-scale evaluation in exposing concrete detection boundaries.
```
