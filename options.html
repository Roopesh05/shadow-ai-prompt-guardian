Developer API (window.SentinelAPI)
On any supported page, you can call SENTINEL's detection engine directly:
// Scan any text
const result = window.SentinelAPI.scan("my text...");
console.log(result.riskScore, result.findings);

// Auto-redact
const redacted = window.SentinelAPI.redact("my text...");

// Get compliance presets
window.SentinelAPI.compliance.hipaa.patterns
